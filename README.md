# Kiosk Browser (Nederlands)

Android-app die een webpagina op volledig scherm toont, met screensaver (klok) en pincode-beveiliging.

- Instellingen openen: 5x tikken in de linkerbovenhoek, daarna pincode (standaard `1234`, direct wijzigen!)
- Afsluiten kan alleen via Instellingen > "Kiosk-app afsluiten"
- Bouwen: `./gradlew assembleDebug` (JDK 17+, Android SDK 35)
- Kant-en-klare APK: `KioskBrowser.apk`
